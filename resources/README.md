# Runtime and packaging resources

This directory contains application icons, platform installer support, and [third-party notices](third-party-licenses/NOTICE.OpenH3.txt). Build scripts prepare additional ignored runtime resources when needed.

Keep assets required by application startup, notifications, development mode and packaging. Product screenshots and small demonstrations belong in [`docs/assets/`](../docs/assets/README.md). Historical marketing videos, generated media, model weights and installers do not belong in the source tree.

Third-party license texts and source-offer materials are distribution evidence, not disposable build output.
