# Getting Help

OpenH3 is an Alpha release. The fastest way to get useful help is to include the exact version, operating system, runtime configuration, and a redacted reproduction.

## Where to ask

- **Community chat:** join QQ group **790631169** using the [QR code in the README](readme.md#openh3-项目社群).

- **How-to questions:** use [Discussions](https://github.com/pigq/OpenH3/discussions) for general usage questions, or the [question issue form](https://github.com/pigq/OpenH3/issues/new?template=question.yml) for structured troubleshooting.
- **Confirmed bugs:** use the [bug report form](https://github.com/pigq/OpenH3/issues/new?template=bug_report.yml).
- **Feature ideas:** use the [feature request form](https://github.com/pigq/OpenH3/issues/new?template=feature_request.yml).
- **Security issues:** follow [SECURITY.md](SECURITY.md); never post them publicly.

## Include these details

- OpenH3 version or commit SHA.
- Windows version and hardware summary.
- Whether the task uses a provider API, local H3, or ComfyUI.
- The smallest prompt or input asset that reproduces the problem.
- Relevant logs or screenshots with API keys, tokens, private URLs, and personal data removed.

Please search existing issues and discussions before opening a new report. Do not upload copyrighted media, private videos, model weights, or credentials unless you have the right to share them.

For installation and first-task instructions, start with the [OpenH3 documentation](docs/README.md) and the [Chinese README](readme.md).
