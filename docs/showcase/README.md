# OpenH3 Showcase

This page shows a recorded product demonstration. It is not a hardware benchmark or a fully pinned reproduction recipe; model revision, parameters and timing must be documented before making those claims. Follow [Getting started](../getting-started/README.md) to test your own environment.

## Reference image to video

The repository includes a UI recording and still previews in [`docs/assets/`](../assets). The flow is:

1. Attach a reference image.
2. Describe camera movement, subject continuity, and duration.
3. Let the local H3 / ComfyUI workflow run.
4. Inspect progress and preview the resulting video in the conversation.

See the bilingual project README for the embedded [demo GIF](../assets/openh3-demo.gif), [reference image](../assets/openh3-reference.png), and [result preview](../assets/openh3-result-preview.png).

The demo assets are interface documentation. They do not grant redistribution rights for any model, LoRA, workflow, or generated media referenced by the recording.
