# Server deployment status

OpenH3 currently documents the desktop workflow as its primary entry point. A maintained standalone Docker deployment is not available in this source revision; the previous Dockerfile referenced removed root scripts and has been retired.

For optional WebUI development, follow the [development guide](../contributing/development.md), then inspect [WebUI usage](webui.md) and the [package map](../../packages/README.md). These entry points are not a promise of a validated public headless server distribution.

Do not install an AionUi package expecting it to be OpenH3. Published OpenH3 platforms and known limitations are listed in [Releases](https://github.com/BHUHD/OpenH3/releases).
