# System Requirements

## Desktop preview

- Windows 10 or Windows 11, x64;
- at least 8 GB RAM for the desktop shell, with more recommended for media work;
- free disk space for the application, caches, source media, and generated results;
- Windows GPU drivers suitable for the selected H3 / ComfyUI workflow.

The Alpha installer is unsigned. Windows may display a source warning until the project has a signed release channel.

## Run from source

- Bun (preferred) or a compatible Node.js/npm installation;
- Git and a working shell;
- a local Provider configuration for agent requests;
- optional H3 / ComfyUI runtime and GPU according to the model's own requirements.

OpenH3 does not bundle model weights. Desktop packages can include third-party runtime components; see the [third-party notices](../../resources/third-party-licenses/NOTICE.OpenH3.txt) for their distribution boundaries. Check the license of each additional model or workflow before using or redistributing it.
