# Roadmap / 路线图

OpenH3 当前处于 Alpha。以下是工作方向，不是交付日期或已实现能力承诺。

| 优先级 | 方向                 | 完成标准                                       |
| ------ | -------------------- | ---------------------------------------------- |
| 当前   | 清晰的仓库与文档入口 | 统一导航、命名和维护边界，保留可复现工程内容   |
| 下一步 | 发布可追溯           | 安装包、版本、tag 与源码提交一致；更新通道明确 |
| 下一步 | 首次视频可复现       | 公开实测硬件、模型版本、输入、步骤及成功标志   |
| 下一步 | 稳定性与排错         | 安装、首启、失败恢复和取消在开发机之外完成验证 |
| 后续   | 平台与工作流扩展     | 根据实际测试结果逐项公布支持范围               |

适合贡献的方向：复现文档问题、提交脱敏错误日志、补充测试覆盖、分享可公开使用的工作流案例。开始较大的改动前，请先在 [Issues](https://github.com/pigq/OpenH3/issues) 说明范围。
