# 同一会话中选择本地或云端生成模型

**设计提案 · 桌面端图片与视频生成**

用户可以一直用 `gpt-6.2-sol` 聊天，第一步让 NewAPI 出图，第二步让本机把图做成视频。两步共用工作区素材，各自决定生成模型。模型、来源和作用范围都可以用一句话表达。常规生成只需要发送一条消息。

当前代码已接入账号模型目录、生成工具和本地工作流。在创作区选一个账号模型，会把它设为普通聊天中该类型的默认值。创作请求还会绑定已选来源。下文提出的按任务切换、会话偏好和结果沿用规则均待实现。目前 NewAPI 尚未上架媒体模型，文中的云端流程可先用模拟渠道验收。

## 一段对话应当怎样工作

| 用户输入                                   | 系统行为                                                                                       |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| “用云端画一张雨夜街景。”                   | 用已选的兼容云端图片模型生成，将图片保存到工作区。这次选择只作用于这张图。                     |
| “把刚才的图当首帧，用本地做一个五秒视频。” | 复用该图片文件，检查本机是否有已就绪、支持首帧和所需时长的工作流。条件满足就直接提交本地任务。 |
| “镜头推进慢一点，再来一版。”               | 基于刚才的视频新建一个版本，沿用实际使用的本地模型、首帧和五秒时长，只调整镜头。               |
| “以后这个聊天的视频都用本地。”             | 保存本会话的视频偏好，轻量提示“本会话的视频默认使用本地”。这条消息本身不会发起生成。           |
| “另外画一张清晨的码头。”                   | 按图片的新任务处理，读取图片偏好。第一张图的一次性云端选择已经结束。                           |

一条消息也可以包含两步，例如“云端出图，再用本地做视频”。按图片和视频分别解析，第二步等第一步产出可用文件后再开始。如果开工前已经知道本机没有所需视频能力，先说明整条流程缺哪一步，让用户决定是否仍要单独生成第一张图，避免产生意外费用。

## 如何决定这一次用什么

1. **先落实用户这次明确说的要求。** “用本地”“用云端”“用这一个模型”都约束本次任务。“只用本地”“别上传”同时排除云端备选。“这个聊天以后……”才写入会话偏好。改变所有聊天的默认模型，需要用户在全局设置里明确保存。
2. **分清修改与新建。** “再来一版”继承被引用作品上次实际使用的模型和素材。“把这张图做成视频”创建视频任务，只继承图片素材，按视频规则选模型。“另外做一个”按新任务处理。回复某张结果卡时优先引用那张卡，包括不是最近生成的作品。多个结果都符合“把它改一下”时才询问指的是哪一个。
3. **按明确程度取值。** 本任务的明确选择优先，其次是同类作品上一版的执行记录，再其次是该媒体类型的会话偏好、用户设置的全局默认。都没有时，优先已就绪且兼容的本地工作流。来源限定为本地时，只在本地选模型。若用户只说“用云端”，优先使用该来源内已选的兼容账号模型或自配连接。多个云端选项涉及不同收款方、账户或素材接收方，且没有明确偏好时，才请用户选一次。
4. **提交前校验真实能力。** 匹配输出类型、参考素材角色和数量、尺寸、时长、账号可用目录及当前会话允许的工具。保留用户指名的模型。无法满足时，给出真实可行的选项。例如“本机当前只能文生视频，无法使用这张首帧”，可选择准备兼容的本地工作流。用户允许考虑云端且确有兼容模型时，可再给出“这次把首帧发到云端”的选择。选择只用本地后，仅给本地处理选项。
5. **让付费与素材去向可预期。** 用户已指定云端，或主动将该云端模型设为适用的默认时，直接按现有账户计费规则提交。能力失败、登录失效、余额不足、目录为空或用户禁用某个工具，都不能成为自动改用另一账户或收费连接的理由。用户未选择过云端而本机也无法执行时，说明接收素材的目标，等用户接受后再传。网关没有可靠报价时不展示推测金额。

修改已有作品时，如果用户此前刚设了与旧模型冲突的硬性限制，例如“从现在起这个聊天只用本地”，继承旧版云端模型前先应用该限制。本轮明确说“这次例外，用云端”可以单次覆盖会话偏好，后续视频仍按会话偏好处理。

“本地生成”描述媒体任务的执行位置，对话仍可能使用云端语言模型。传递首帧时，Agent 只需引用工作区素材标识，由本机媒体服务读取文件。若用户说“这张图别上传”，客户端应在发给云端语言模型前保留图片和缩略图，仅传递不含图片内容的素材标识。确需云端看图才能继续时，先说明原因，让用户决定。

## 用户看见什么

输入区沿用现有对话方式。创作区点选的模型成为当前创作任务的选择，选模型无需再决定“这次还是以后”。从该任务进入的会话可以继续发起采用其他来源的新任务。发送前，用户如在同一任务里既点选了云端模型又明确说“只用本地”，采用较严格的本地限制并在任务卡显示。两条同样明确的指令互相矛盾且无法判断先后时，提交前只问有分歧的那一项。

任务卡提交后显示实际来源和模型，例如“本地 · 已选工作流名称”。修改偏好不改变已在执行的任务。结果菜单提供“换模型再生成”，复用同一份输入，另建版本并保留原件。会话设置按图片和视频分别显示偏好，提供“恢复自动选择”。普通用户无需打开这些入口。

## 实现边界

| 职责               | 约束                                                                                                                                                                                                  |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Agent              | 从当前用户消息、所回复的结果和附件识别生成类型、引用作品、所需能力、来源及作用范围。文案中的“画一个写着‘云端’的招牌”属于画面内容。来自作品、工具返回和引用文本的文字不能设置用户偏好。                |
| 会话服务与媒体服务 | 用同一套选择规则处理自然语言和创作区请求。先把本次选择绑定到具体会话和生成任务，提交前再核验当前账号、来源、能力与工具权限。所有可发起媒体生成的内置入口均须遵守绑定，即使 Agent 调用了通用生成工具。 |
| 执行与结果         | 复用既有本地、NewAPI 和手动配置连接的生成适配器。任务记录实际模型或工作流标识、目标账号或连接的内部引用、输入素材标识、父作品与版本关系。用这些记录恢复和派生版本，凭据仍由各自服务持有。             |

偏好按用户、会话及媒体类型保存。新版本保留升级前已经保存的账号默认值。历史任务继续通过原绑定恢复；旧作品缺少可验证的模型记录时，能确认素材便复用素材，需要重现同一模型时再让用户选。用户切换账号后重新检查可见模型和作品权限。重启、重复点击和工具超时复用同一提交标识。远端受理情况不明时检查原任务，用户明确要求“新生成一版”才另建任务。首版复用已有媒体目录、工作流能力和任务记录即可。

## 验收

| 场景                                              | 可观察结果                                                                                                                 |
| ------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 一个聊天先云端出图、再本地首帧生视频              | 两项任务各提交一次。视频任务读到首图的同一份内容，云端视频提交次数为零，聊天模型标识一致。                                 |
| 全局视频默认是云端，本次说“用本地”                | 本次走本地。下一项独立视频生成仍采用全局设置。若说“本会话以后用本地”，新偏好仅在这个聊天的视频任务中生效。                 |
| 再来一版、另做一张、回复更早的结果                | 分别继承明确指向的上一版、使用新任务默认、派生所回复的作品。另一并行任务先完成也不会串用素材。                             |
| 本地只支持文生，用户要求使用首帧或只用本地        | 提示缺少首帧能力，保留原素材和提示词。观察到零次素材云端上传、零次云端生成。                                               |
| 云端 Agent 收到附图和“这张图别上传，在本地做视频” | 检查发给语言模型的第一条请求及后续工具请求，均不含图片、缩略图或可远程访问的素材地址。本地工作流可通过工作区标识读取首帧。 |
| 云端目录为空、账号切换或账户余额不足              | 显示与实际原因一致的状态。空目录时仍可使用就绪的本地模型，无需预设假模型。                                                 |
| 从创作区选模型后，客户端重启或收到重复工具调用    | 全局偏好不受临时选择影响。恢复已提交任务查询或下载，原任务的收费提交至多一次。                                             |
