# Built-in creation examples

This gallery contains 48 image examples and four playable video references.
The original eight image examples and four videos are stock media. The 40
additional image examples and prompts were selected from the user-provided
`生图模板汇总(1).html` export on 2026-10-16. The gallery uses bundled files and makes no third-party
requests at runtime. Selecting a template copies its prompt only, without
submitting a job or attaching the preview as a reference.

The imported examples are grouped under `art/`, `style/`, `portraits/`, `film/`,
and `fantasy/`. Their previews are 560-pixel-wide WebP files. These templates
require the user to upload their own reference image; the prompt asks for it
when it is missing. Their original prompts are preserved, with a localized
reference reminder and the intended output ratio added when selected.

Images are resized WebP files. Videos are six-second, silent H.264 MP4 previews
with a 640-pixel width and a fast-start header. Video posters are extracted from
the corresponding clips. Media is checked in alongside the renderer so Vite
emits usable URLs in both desktop and WebUI builds.
