# Tests

| Directory | Purpose |
| --- | --- |
| `unit/` | Fast unit, DOM, renderer, media, and H3 runtime tests |
| `integration/` | Multi-module integration checks |
| `e2e/` | End-to-end desktop and WebUI scenarios |
| `fixtures/` | Small deterministic test inputs |

Feature work should add focused tests beside the affected area under `unit/`. Do not commit downloaded models, runtime bundles, API keys, screenshots, or local test output.
